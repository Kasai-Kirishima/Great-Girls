# Great Girls (GG) — v0.7

Офлайн браузерная коллекционная карточная игра. Запуск: открыть `index.html` в современном браузере или разместить папку на GitHub Pages.

## Изменения v0.7
- У Юбель оставлены три способности; удалён четвёртый особый приём.
- Вместо арены со списком ботов добавлен случайный подбор соперника.
- Игрок собирает отряд из трёх карточек, находит одного из 30 ботов, может сменить найденного соперника и начать бой.
- После завершения матча возврат ведёт обратно к подбору соперника.

## Изменения v0.6
- В каталог добавлен фильтр по аниме/вселенной.
- Арт карточек стал выше (вертикальное соотношение 2:3), чтобы меньше обрезать портреты.
- Из интерфейса убраны списки и подсказки с известными промокодами. Поле активации сохранено; действующие коды и одноразовая проверка продолжают работать.

## Структура
- `assets/css/` — стили и темы.
- `assets/js/data.js` — карточки, предметы и игровые данные.
- `assets/js/modules/` — независимые игровые подсистемы.
- `assets/js/bots.js` — данные ботов.

Профиль и прогресс хранятся локально в браузере. Облачная синхронизация и PvP не подключены.
